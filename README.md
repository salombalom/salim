# دَرْسي (Darsi)

تطبيق تعليمي **مجاني بالكامل** لطلاب المدارس في سلطنة عُمان، من الصف الأول إلى الثاني عشر ولكل المواد.
لا اشتراكات، ولا محتوى مقفل، ولا إعلانات.

> **الوضع الحالي: محلي بالكامل** (`config/app.ts` ← `LOCAL_ONLY = true`). يعمل التطبيق بلا تسجيل دخول، وتظهر فيه كل الأسئلة الـ720، ويُحفظ التقدّم على الجهاز. لتفعيل Supabase لاحقاً اجعل القيمة `false` واتبع قسم «ربط Supabase».
>
> المرحلة الحالية: **المرحلة 2**. أُضيف ربط Supabase: تسجيل الدخول برمز، وحفظ التقدّم في حسابك، والنقاط والسلسلة اليومية تُحسب على الخادم.
> التطبيق يعمل أيضاً دون Supabase في «وضع التجربة».

## تشغيل التطبيق على جوالك بـ Expo Go (خطوة بخطوة)

### 1) ثبّت البرامج على حاسوبك (مرة واحدة فقط)
1. **Node.js**: من الموقع https://nodejs.org حمّل نسخة **LTS** (الزر الأخضر) وثبّتها كأي برنامج.
   - للتأكد: افتح «الطرفية» (Terminal في ماك، أو PowerShell في ويندوز) واكتب:
     ```bash
     node -v
     ```
     إذا ظهر رقم مثل `v22.x.x` فالتثبيت صحيح.
2. **Git**: من https://git-scm.com حمّله وثبّته.

### 2) ثبّت تطبيق Expo Go على جوالك
- آيفون: من App Store، ابحث عن **Expo Go**.
- أندرويد: من Google Play، ابحث عن **Expo Go**.

> تأكد أن نسخة Expo Go **محدَّثة لآخر إصدار**، لأن المشروع يستخدم Expo SDK 58.

### 3) حمّل المشروع على حاسوبك
في الطرفية اكتب الأوامر التالية واحداً تلو الآخر:
```bash
git clone https://github.com/salombalom/salim.git
cd salim
npm install
```
الأمر الأخير يحمّل المكتبات وقد يستغرق بضع دقائق في المرة الأولى.

### 4) شغّل التطبيق
```bash
npx expo start
```
سيظهر **رمز QR** في الطرفية. بعدها:
- **آيفون**: افتح تطبيق **الكاميرا** ووجّهه إلى الرمز، ثم اضغط على الإشعار الذي يظهر.
- **أندرويد**: افتح تطبيق **Expo Go** واضغط **Scan QR code**.

**مهم**: يجب أن يكون الجوال والحاسوب على **نفس شبكة الواي فاي**.
إذا لم يعمل الاتصال، أوقف التشغيل بالضغط على `Ctrl + C` ثم شغّل:
```bash
npx expo start --tunnel
```

### 5) ملاحظات عند التشغيل الأول
- في المرة الأولى **قد يُعاد تحميل التطبيق تلقائياً مرة واحدة**. هذا طبيعي، ويحدث لتفعيل اتجاه الواجهة من اليمين إلى اليسار.
- أي تعديل تحفظه في الكود يظهر على الجوال فوراً.
- لإيقاف التشغيل اضغط `Ctrl + C` في الطرفية.

## فتح التطبيق على جوالك مباشرة (بدون حاسوب)

التطبيق منشور على حسابك في Expo (المشروع `@salombalom/darsi`). لفتحه:
1. ثبّت تطبيق **Expo Go** من App Store أو Google Play، وتأكد أنه محدَّث.
2. افتح الرابط التالي على الجوال، أو امسح رمز QR الخاص به:
   ```
   exp://u.expo.dev/b8fbeeb7-4095-44fd-bca9-91d74b07f338/group/204948f2-d0ea-429d-ab37-7934c8b58d41
   ```
   - **أندرويد:** افتح Expo Go واضغط **Scan QR code**.
   - **آيفون:** وجّه تطبيق الكاميرا إلى رمز QR.
3. يمكنك أيضاً فتح صفحة التحديثات في حسابك ومسح رمز QR منها: https://expo.dev/accounts/salombalom/projects/darsi/updates

### نشر نسخة جديدة بعد أي تعديل
```bash
npx eas-cli login          # مرة واحدة على حاسوبك
npm run publish:preview -- --message "وصف التعديل"
```
بعد النشر يظهر رابط جديد في صفحة التحديثات على expo.dev.

## ربط Supabase (تسجيل الدخول وحفظ التقدّم) — خطوة بخطوة

بدون هذه الخطوات يعمل التطبيق في «وضع التجربة» فقط. نفّذها مرة واحدة.

### 1) أنشئ مشروعاً على Supabase
1. ادخل إلى https://supabase.com وأنشئ حساباً مجانياً.
2. اضغط **New project**، واكتب اسماً مثل `darsi`، واختر كلمة مرور قوية لقاعدة البيانات واحفظها عندك.
3. اختر المنطقة الأقرب، مثل **Mumbai** أو **Frankfurt**، ثم انتظر دقيقتين حتى يجهز المشروع.

### 2) أنشئ الجداول وأضف المحتوى
في الطرفية داخل مجلد المشروع، شغّل الأوامر التالية بالترتيب:
```bash
npm run db:login                 # يفتح المتصفح لتسجيل الدخول إلى Supabase
npm run db:link -- <project-ref> # project-ref تجده في رابط مشروعك: supabase.com/dashboard/project/<project-ref>
npm run db:push                  # ينشئ الجداول والصلاحيات ويضيف الصفوف والمواد و720 سؤالاً
```
عند الأمر الثاني سيطلب كلمة مرور قاعدة البيانات التي حفظتها في الخطوة 1.

### 3) فعّل رسالة الرمز بالعربي
1. في لوحة Supabase اذهب إلى: **Authentication ← Emails ← Magic Link**.
2. اجعل العنوان (Subject): `رمز الدخول إلى دَرْسي`.
3. انسخ محتوى الملف `supabase/templates/magic_link.html` والصقه مكان المحتوى الموجود، ثم احفظ.

هذه الخطوة **ضرورية**، لأن الرسالة الافتراضية ترسل رابطاً بدل الرمز المكوّن من 6 أرقام.

### 4) ضع المفاتيح في التطبيق
1. في لوحة Supabase اذهب إلى **Project Settings ← API Keys**.
2. انسخ **Project URL** والمفتاح العام (**anon** أو **publishable**).
3. في مجلد المشروع انسخ الملف `.env.example` إلى ملف جديد اسمه `.env`، وضع فيه القيمتين:
   ```
   EXPO_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=...
   ```
4. أوقف التطبيق بـ `Ctrl + C`، ثم شغّله من جديد بـ `npx expo start --clear`.

> لا تضع مفتاح **service_role** أو **secret** في التطبيق أبداً. المفتاح العام آمن لأن قاعدة البيانات محمية بسياسات RLS.

### 5) اجعل نفسك مسؤولاً (أدمن)
بعد أن تسجّل الدخول في التطبيق مرة واحدة ببريدك، اذهب إلى **SQL Editor** في لوحة Supabase وشغّل:
```sql
insert into public.admins (user_id)
select id from auth.users where email = 'بريدك@example.com';
```
ستحتاج هذا في المرحلة 6 (لوحة الإدارة) لمراجعة الأسئلة وتعديل المحتوى.

### ملاحظات مهمة
- **حد رسائل البريد:** خدمة البريد المجانية المدمجة في Supabase ترسل عدداً قليلاً جداً من الرسائل في الساعة، وتصلح للتجربة فقط. قبل الإطلاق اربط خدمة بريد مثل Resend أو Brevo من: **Authentication ← Emails ← SMTP Settings**.
- **الدخول برقم الهاتف** يحتاج مزوّد رسائل SMS مدفوعاً، مثل Twilio أو MessageBird أو Vonage. فعّله من **Authentication ← Sign In / Providers ← Phone**. إلى أن تفعّله، يظهر للمستخدم أن الدخول بالهاتف غير مفعّل، ويستطيع استخدام البريد.
- **الأسئلة لا تظهر للطلاب إلا بعد مراجعتها** (`reviewed = true`). إلى أن تتوفر لوحة الإدارة في المرحلة 6، يمكنك اعتماد أسئلة درس معيّن من SQL Editor:
  ```sql
  update public.questions set reviewed = true where lesson_id = 'g5-math-u1-l1';
  ```
- **وضع التجربة:** عند أول تسجيل دخول يُنقل تقدّم وضع التجربة إلى الحساب الجديد تلقائياً. إذا كان الحساب مستخدماً من قبل، يبقى تقدّم الحساب كما هو.
- **حذف الحساب:** متاح من «حسابي». هذا شرط من شروط App Store وGoogle Play.

## ماذا تجد في المرحلة 1؟
- شاشة ترحيب، ثم تسجيل الدخول. الدخول بالبريد أو الهاتف يُفعَّل في المرحلة 2، وخيار «تجربة بدون حساب» يعمل الآن.
- اختيار الدور (طالب / ولي أمر) ثم الصف.
- الرئيسية: المواد بأيقونات وألوان، والتقدم في كل مادة، والسلسلة اليومية، والنقاط، ووقت الدراسة اليوم.
- شاشة المادة: الفصلان الدراسيان، ثم الوحدات، ثم الدروس، مع نسبة الإنجاز والنجوم.
- شاشة الدرس بأربعة تبويبات. **الملخص** يعرض أهداف الدرس، و**الاختبار** يعمل الآن، أما **الفيديوهات** و**الكتاب** فتُفعَّل في المرحلتين 3 و4.
- الاختبار: سؤال في كل مرة، وشريط تقدم، وتصحيح فوري مع الشرح، وأصوات، واهتزاز خفيف.
  - أنواع الأسئلة: اختيار من متعدد، صح أو خطأ، أكمل الفراغ، ترتيب الكلمات.
  - في الرياضيات تُضاف **أسئلة جديدة مولَّدة تلقائياً** في كل مرة حسب الصف.
- شاشة النتيجة: الدرجة، والنجوم، والنقاط، وزر «راجع أخطائي».
- «أخطائي»: كل سؤال أخطأت فيه، لتعيد حله. يُحذف السؤال من القائمة عندما تحله بشكل صحيح.
- «المحفوظات» (تمتلئ عند إضافة الفيديوهات والملخصات)، و«حسابي» مع الإعدادات: الاسم المعروض، والصف، والوضع الليلي/النهاري، وحجم الخط، والأصوات، وتسجيل الخروج.
- «عن التطبيق» و«سياسة الخصوصية» (عربي وإنجليزي، مسودة أولية).

### الأسئلة غير المراجَعة
كل الأسئلة المبدئية (720 سؤالاً) كتبها الذكاء الاصطناعي، وهي معلَّمة **غير مراجَعة**. **لا تظهر للطلاب** إلا بعد أن تراجعها.
- أثناء التطوير على Expo Go تظهر هذه الأسئلة تلقائياً، وعليها شارة «غير مراجَع».
- يمكنك التحكم في ذلك من: **حسابي ← للمطوّر ← عرض الأسئلة غير المراجَعة**.
- في نسخة المتجر يكون هذا الخيار مطفأً افتراضياً.
- ستراجع الأسئلة وتعتمدها من لوحة الإدارة في المرحلة 6.

## تعديل الصفوف والمواد
كل الصفوف والمواد وألوانها وأيقوناتها في ملف واحد: **`config/curriculum.ts`**.
- لتغيير أيقونة مادة: عدّل `SUBJECTS`. الأيقونات من مكتبة Lucide (https://lucide.dev/icons)، وإذا أردت أيقونة جديدة أضفها أولاً في `components/icons.tsx`.
- لتغيير ألوان التطبيق أو ألوان المواد أو الخطوط: كلها في ملف واحد هو **`theme/tokens.ts`**.
- لتغيير مواد صف معيّن: عدّل `GRADE_SUBJECTS`.

## تعديل الأسئلة المبدئية
الأسئلة موجودة في `seed/content/grade01.ts` حتى `grade12.ts`. مثال:
```ts
mcq('كم عدد أركان الإسلام؟', ['ثلاثة', 'أربعة', 'خمسة', 'ستة'], 2, 'الشرح هنا'),
tf('الصلاة ركن من أركان الإسلام.', true, 'الشرح'),
fill('أول سورة في المصحف هي سورة ____.', 'الفاتحة', 'الشرح'),
order('أنا أحب مدرستي', 'الشرح'),
```
- الرقم `2` في سؤال الاختيار من متعدد هو ترتيب الإجابة الصحيحة، والعدّ يبدأ من `0`.

## أوامر مفيدة
| الأمر | ماذا يفعل |
|---|---|
| `npx expo start` | تشغيل التطبيق |
| `npm test` | تشغيل الاختبارات الآلية (التصحيح، والنقاط، والسلسلة، ومولّد الرياضيات، وسلامة الأسئلة) |
| `npm run typecheck` | فحص أخطاء الكتابة في الكود |
| `npm run lint` | فحص جودة الكود |
| `npm run db:test` | اختبار قاعدة البيانات والصلاحيات (RLS) محلياً، ويحتاج PostgreSQL مثبتاً |
| `npm run db:seed-sql` | إعادة توليد `supabase/seed.sql` بعد تعديل أسئلة `seed/` |
| `npm run db:push` | رفع التعديلات على قاعدة البيانات إلى Supabase |

## حل المشاكل الشائعة
- **«Project is incompatible with this version of Expo Go»**: حدّث تطبيق Expo Go من المتجر.
- **الجوال لا يتصل**: تأكد من نفس الواي فاي، أو استخدم `npx expo start --tunnel`.
- **الواجهة ظهرت من اليسار لليمين**: أغلق التطبيق تماماً من الجوال وافتحه مرة أخرى.
- **أخطاء بعد `git pull`**: شغّل `npm install` مرة أخرى.

## هيكل المشروع (مختصر)
```
app/          الشاشات (كل ملف = شاشة)
components/   عناصر التصميم المشتركة والأيقونات
theme/        ملف الألوان والخطوط والمسافات (tokens.ts)
config/       المنهج (الصفوف والمواد) وسياسة الخصوصية
lib/          المنطق: التصحيح، النقاط، مولّد الرياضيات، الحالة المحفوظة
seed/         الأسئلة المبدئية الأصلية
supabase/     قاعدة البيانات: migrations (الجداول والصلاحيات)، seed.sql، الاختبارات
__tests__/    الاختبارات الآلية
legacy/       لعبة قديمة منفصلة (للاحتفاظ بها فقط)
```

## الخصوصية
لا إعلانات، ولا أدوات تتبع إعلانية، ولا جمع لبيانات غير ضرورية. في وضع التجربة يُحفظ كل شيء على الجهاز فقط.
