# اركض يا بطل 🏃‍♂️

لعبة جري لا نهائية ثلاثية الأبعاد تشتغل بالمتصفح (كمبيوتر وجوال).
مبنية بـ Three.js و Vite و JavaScript عادي.

## التشغيل

لازم يكون عندك Node.js (نسخة 20 أو أحدث).

```bash
npm install
npm run dev
```

- **الكمبيوتر:** افتح `http://localhost:5173`
- **الجوال:** خلّ الجوال على نفس شبكة الواي فاي، وافتح رابط `Network` اللي يطلع في الطرفية
- **عداد الإطارات:** أضف `?fps` لآخر الرابط

## التحكم

| الحركة | الكيبورد | الجوال |
|---|---|---|
| يمين / يسار | ← → أو A / D | اسحب يمين / يسار |
| قفز | ↑ أو W أو المسافة | اسحب لفوق |
| انزلاق | ↓ أو S | اسحب لتحت |

## النتيجة

النتيجة = المسافة بالمتر + (كل عملة × 10). أعلى نتيجة تنحفظ في المتصفح.

## الملفات

| الملف | وش فيه |
|---|---|
| `src/main.js` | يربط كل شي ببعض + حلقة اللعبة وحالاتها |
| `src/config.js` | الأرقام القابلة للتعديل (السرعة، القفز...) |
| `src/world.js` | المشهد، الكاميرا، الإضاءة، الطريق والمباني |
| `src/player.js` | الشخصية (باللبس العماني) وحركاتها |
| `src/input.js` | الكيبورد والسحب |
| `src/obstacles.js` | العقبات والاصطدام |
| `src/coins.js` | العملات وجمعها |
| `src/ui.js` | الشاشات والعدادات وحفظ أعلى نتيجة |
| `src/style.css` | تنسيق الواجهة |

## نشرها أونلاين

```bash
npm run build
```
يطلع مجلد `dist` تقدر ترفعه على أي استضافة ملفات ثابتة (GitHub Pages، Netlify...).
