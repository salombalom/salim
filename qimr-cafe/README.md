# قالب كافيه قِمْر ☕

قالب موقع عربي (RTL) لأي كافيه أو مطعم: واجهة فخمة، ومنيو بأقسام، وسلة، وإرسال الطلب على واتساب، وقسم «زورونا» بخريطة قوقل وأوقات الدوام، وصفحة منيو خفيفة تنفتح من كود QR على الطاولة.

**كل بيانات المحل في ملف واحد: `config.json`.** لما يجيك زبون جديد، تغيّر هذا الملف وتنشر، وما تلمس أي ملف ثاني.

البيانات الحالية لكافيه وهمي في نزوى («بُنّ الفلج») للعرض فقط.

---

## التشغيل محلياً

يحتاج Node.js نسخة 18 أو أحدث.

```bash
cd qimr-cafe
npm install
npm run dev
```

| الرابط | الصفحة |
|---|---|
| `http://localhost:3000` | الموقع الكامل |
| `http://localhost:3000/menu` | منيو الطاولة (اللي يفتحه كود QR) |
| `http://localhost:3000/menu?table=5` | منيو الطاولة ورقم الطاولة معبّأ تلقائياً |
| `http://localhost:3000/qr` | بطاقة QR جاهزة للطباعة |

أي تعديل في `config.json` أو `src/` يعيد البناء تلقائياً، وبعدها حدّث الصفحة.

## الأوامر

| الأمر | وش يسوي |
|---|---|
| `npm run dev` | يشغّل الموقع محلياً ويعيد البناء مع كل تعديل |
| `npm run build` | يبني الموقع النهائي في مجلد `dist/` (هذا اللي يُنشر) |
| `npm run qr` | يولّد صورة QR لصفحة المنيو في `qr/menu-qr.png` و `qr/menu-qr.svg` |
| `npm run qr -- https://رابط-ثاني` | نفس الشي، لكن برابط تحدده بنفسك |

البناء يتحقق من `config.json`، ولو فيه خطأ (سعر مكتوب كنص، أو `id` مكرر، أو وقت بصيغة غلط) يطلع لك رسالة بالعربي توضّح وين المشكلة.

## تجهيز الموقع لزبون جديد

افتح `config.json` وعدّل الأقسام التالية:

### `business`: بيانات المحل
| الحقل | المثال | ملاحظة |
|---|---|---|
| `slug` | `"bunn-alfalaj"` | اسم إنجليزي قصير بدون مسافات (تُحفظ السلة باسمه) |
| `name` | `"بُنّ الفلج"` | |
| `tagline` | `"قهوة مختصة بروح نزوى"` | يظهر في الفوتر وعنوان الصفحة |
| `description` | | وصف يظهر في قوقل وفي معاينة الرابط بالواتساب |
| `logo` | `"assets/logo.svg"` | حط الملف في `src/assets/`. ملف SVG يتلوّن تلقائياً مع الوضع الليلي، و PNG يُعرض كما هو |
| `siteUrl` | `"https://my-cafe.vercel.app"` | **رابط الموقع بعد النشر.** منه يُولَّد كود QR |

### `contact`
- `whatsapp`: رقم الواتساب **مع رمز الدولة وبدون + أو 00**، مثل `96891234567`. **كل الطلبات توصل لهذا الرقم.**
- `phone`: لزر «اتصل».
- `instagram` / `tiktok` / `snapchat`: اسم الحساب فقط بدون @. اتركه `""` لو ما فيه حساب.

### `location`
- `address` و `city`: النص اللي يظهر للزبون.
- `lat` و `lng`: الإحداثيات. من قوقل ماب: اضغط ضغطة طويلة على موقع المحل وانسخ الرقمين اللي يطلعون.

### `hours`: أوقات الدوام
```json
{ "label": "السبت – الأربعاء", "days": [6, 0, 1, 2, 3], "open": "06:30", "close": "23:30" }
```
- الأيام أرقام: `0` الأحد، `1` الاثنين، `2` الثلاثاء، `3` الأربعاء، `4` الخميس، `5` الجمعة، `6` السبت.
- الوقت بصيغة 24 ساعة. لو الإغلاق بعد منتصف الليل اكتبه عادي (مثلاً `"01:00"`) والموقع يفهمه.
- شارة «مفتوح الآن / مغلق الآن» تُحسب تلقائياً بتوقيت مسقط.

### `order`: إعدادات الطلب
- `types`: طرق الطلب المتاحة، أي مجموعة من `"pickup"` (استلام) و `"delivery"` (توصيل) و `"dinein"` (على الطاولة).
- `deliveryFee`: رسوم التوصيل (تنضاف للإجمالي تلقائياً).
- `deliveryMinimum`: الحد الأدنى لطلب التوصيل (`0` يعني بدون حد أدنى).
- `currency` و `decimals`: العملة وعدد الخانات العشرية (الريال العُماني: 3).

### `theme`: الألوان والخطوط
- `light` و `dark`: ألوان الوضع النهاري والليلي. غالباً يكفي تغيّر `primary` (اللون الأساسي) و `accent` (لون التمييز).
- لون النص فوق الأزرار يُختار تلقائياً (فاتح أو غامق) حسب الأوضح.
- `fonts`: أي خط من [Google Fonts](https://fonts.google.com/?subset=arabic). `display` للعناوين و `body` للنص.

### `hero` و `about` و `marquee`
نصوص الواجهة والصور. استخدم `\n` داخل العنوان لكسر السطر.

### `menu`: المنيو
```json
{
  "id": "coffee", "name": "قهوة", "icon": "☕",
  "items": [
    { "id": "latte", "name": "لاتيه", "desc": "وصف قصير", "price": 1.800, "image": "...", "tag": "الأكثر طلباً" }
  ]
}
```
- `id` لازم يكون **بالإنجليزي وفريد** لكل صنف.
- `price` رقم بدون علامات تنصيص: `1.800` وليس `"1.800"`.
- `tag` اختياري: شارة صغيرة مثل «جديد» أو «توقيع المحل».
- `"available": false` يخفي زر الإضافة ويكتب «نفد اليوم».

### الصور
- **صور Unsplash** (`https://images.unsplash.com/photo-…`): الموقع يطلب منها الحجم المناسب للجوال أو الكمبيوتر تلقائياً.
- **صور المحل الحقيقية (الأفضل):** حطها في مجلد `public/images/` واكتب المسار مثل `"images/latte.jpg"`. يُفضّل تصغيرها قبل الرفع (عرض 800 بكسل، صيغة WebP أو JPG، وأقل من 150KB لكل صورة).

### `demo`
`true` يكتب في الفوتر إن الموقع تجريبي. **غيّره إلى `false` للزبون الحقيقي.**

## النشر المجاني على Vercel

1. ارفع المشروع على GitHub (هذا المستودع موجود عليه).
2. ادخل [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub.
3. اضغط **Add New… → Project** واختر المستودع.
4. في **Root Directory** اضغط **Edit** واختر مجلد `qimr-cafe`. هذي أهم خطوة لأن المستودع فيه مشاريع ثانية.
5. خلّ **Framework Preset** على **Other**. باقي الإعدادات تُقرأ تلقائياً من `vercel.json` (أمر البناء `npm run build` ومجلد النشر `dist`).
6. اضغط **Deploy**. بعد دقيقة تقريباً يطلع لك رابط مثل `https://qimr-cafe.vercel.app`.
7. **مهم:** حط الرابط الجديد في `business.siteUrl` داخل `config.json` وارفع التعديل. Vercel يعيد النشر تلقائياً، وكود QR في `/qr` يصير يفتح الرابط الصحيح.
8. ولّد صورة QR للطباعة: `npm run qr` (أو افتح `/qr` في الموقع واطبع البطاقة مباشرة).

**دومين خاص للزبون** (مثل `bunnalfalaj.om`): من مشروعك في Vercel ادخل **Settings → Domains** وأضف الدومين واتبع التعليمات، وبعدها حدّث `siteUrl` وولّد QR جديد.

**لكل زبون جديد:** انسخ مجلد `qimr-cafe` لمستودع جديد (أو فرع جديد)، وعدّل `config.json`، وسوّ مشروع Vercel جديد له.

## النشر على Netlify (بديل)

1. ادخل [app.netlify.com](https://app.netlify.com) ← **Add new site → Import an existing project** واختر المستودع.
2. **Base directory:** `qimr-cafe`. الأمر ومجلد النشر يُقرأن من `netlify.toml`.
3. **Deploy**.

أو بدون GitHub: شغّل `npm run build` واسحب مجلد `dist/` إلى [app.netlify.com/drop](https://app.netlify.com/drop).

## هيكل المشروع

```
qimr-cafe/
├── config.json          ← بيانات المحل (الملف الوحيد اللي تعدّله)
├── src/assets/
│   ├── style.css        ← التصميم
│   ├── app.js           ← السلة والواتساب وأوقات الدوام والحركات
│   └── logo.svg         ← الشعار
├── public/              ← ملفات تُنسخ كما هي (favicon، صور المحل)
├── scripts/
│   ├── build.mjs        ← يبني الموقع من config.json
│   ├── templates.mjs    ← قوالب الصفحات
│   ├── dev.mjs          ← خادم التطوير المحلي
│   └── qr.mjs           ← مولّد كود QR
├── qr/                  ← صور QR الجاهزة للطباعة
├── vercel.json / netlify.toml
└── dist/                ← الناتج النهائي (يُولَّد تلقائياً، لا تعدّل فيه)
```

**ليش بدون فريمورك؟** الموقع يُبنى مرة وحدة إلى HTML جاهز، فالمنيو يظهر فوراً حتى قبل تحميل الجافاسكربت. صفحة المنيو كاملة حوالي 15KB مضغوطة، وهذا مهم لأن أغلب الزباين يدخلون من QR بنت الجوال.
