# لوحة إدارة «دَرْسي»

لوحة ويب ثابتة (Next.js) لمراجعة المحتوى قبل أن يراه الطلاب:

| الصفحة | ماذا تفعل فيها |
|---|---|
| الرئيسية | عدد الأسئلة المعتمدة، والملخصات والفيديوهات التي تنتظر المراجعة، وآخر جلب للفيديوهات |
| الأسئلة | قراءة كل سؤال وإجابته وشرحه، ثم «اعتماد» أو «تعديل النص» (أو اعتماد صفحة كاملة) |
| الملخصات | «توليد» ملخص بـ Claude (مسودة)، ثم «مراجعة وتعديل» ثم «اعتماد» |
| الفيديوهات | الفيديوهات الجديدة من القنوات: اختيار الدرس أو «على مستوى المادة» ثم اعتماد أو رفض |
| الكتب | تعديل عنوان أو رابط كتاب (روابط فقط) |
| القنوات | إضافة قناة يوتيوب تعليمية أو إيقافها |

## الأمان
- اللوحة تستخدم **المفتاح العام فقط** (نفس مفتاح التطبيق). لا تضع مفتاح `service_role` هنا أبداً.
- الحماية من قاعدة البيانات نفسها: كل جداول المحتوى مقفلة على `is_admin()` (RLS)، فلو فتح أحد اللوحة بحساب عادي لن يستطيع تعديل شيء.
- مفتاح Claude موجود في أسرار Supabase فقط، وتستدعيه الدالة `generate-summary` من الخادم.

## التشغيل
1. فعّل Supabase أولاً (انظر README الرئيسي، قسم «ربط Supabase»).
2. أنشئ `admin/.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=المفتاح العام
   ```
3. سجّل الدخول مرة واحدة من التطبيق ببريدك، ثم اجعل حسابك مشرفاً من **SQL Editor**:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'بريدك@example.com';
   ```
4. شغّل اللوحة:
   ```bash
   cd admin
   npm install
   npm run dev        # http://localhost:3001
   ```
5. للنشر: `npm run build` ينتج مجلد `admin/out` (ملفات ثابتة). ارفعه على أي استضافة ثابتة (مثل Netlify أو Cloudflare Pages أو Vercel).

## توليد الملخصات
```bash
npx supabase secrets set ANTHROPIC_API_KEY=...        # مرة واحدة
npx supabase functions deploy generate-summary
```
ثم من صفحة «الملخصات»: «توليد الناقص». كل ملخص يبقى **مسودة** حتى تعتمده.
